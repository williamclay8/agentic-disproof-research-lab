# Project Boundary

Trading Lab is a separate Agentic Trading Agent research project. Its dashboard
articles and evidence views should remain separate from Vanta and the Vanta
privacy suite until Clay explicitly decides to merge, publish, or cross-link
them.

## What Stays Here

- Offline falsification dashboards in `reports/`.
- Durable run evidence in `runs/`.
- Trading research ledgers and design notes in `docs/`.
- Local research code under `src/trading_lab/`.
- Examples, fixtures, and tests that support the Trading Lab workflow.

## What Must Not Bleed Into Vanta Yet

- Dashboard copy, article sections, or visual patterns from this project.
- Trading-agent concepts, claims, or research narratives.
- Evidence ledgers or generated reports.
- Any implication that Trading Lab is part of the privacy suite.

## Temporary Integration Policy

Until Clay says otherwise, agents should use one of these safer patterns when
they notice overlap:

- Leave the content in this repository and add a note here.
- Propose a future cross-link without editing Vanta.
- Create a separate export artifact that is clearly labeled Trading Lab.
- Ask Clay before moving, merging, or reusing the material.

The default answer to "should this merge with Vanta?" is no for now.
