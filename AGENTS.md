## Project Boundary

This repository is the standalone Agentic Trading Agent / Trading Lab project.
Keep its research, dashboards, reports, generated articles, ledgers, and design
ideas separate from Vanta and the Vanta privacy suite unless Clay explicitly
asks for a merge or migration in the current thread.

Operational rules for agents:

- Do not copy, summarize, import, route, or blend Trading Lab dashboard content
  into Vanta site pages, Vanta docs, privacy-suite messaging, Vanta Vault notes,
  or Vanta product surfaces without explicit approval.
- Do not treat `reports/`, `runs/`, `docs/agentic-disproof-loop-ledger.md`, or
  dashboard-like articles as source material for privacy-suite pages.
- If a task mentions both Trading Lab and Vanta, default to separation: create
  a boundary note, export, or link proposal here instead of editing the Vanta
  site.
- Keep Trading Lab claims scoped to offline research falsification. It is not a
  privacy product, broker integration, trading execution system, investment
  advisor, or Vanta module.
- Never revert or discard dirty changes unless Clay explicitly asks.

Lumi hygiene:

- Track whether changes are local, committed, pushed, and deployed/live.
- If changes are ready to keep, nudge toward committing them so the tree stays
  clean.
- If a change needs to be visible on a live website, confirm deployment status
  or clearly call out the remaining deployment step.
